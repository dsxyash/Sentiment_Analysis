A sentiment analysis was conducted where text mining and natural language processing was involved. Text classification algorithms were explored and utilized with libraries such as Pandas, and NLTK, whereas some models were built using Scikit-Learn, and a Convolutional Neural Network (CNN) was built by using the Keras API within TensorFlow. The dataset that was used was containing 1.6 million tweets, where the main aim was to determine if a text was seen as a sentiment that was negative or positive.
